# Projectplanning – Boekenwinkel

## 1. Projectdoel

Het doel van dit project is een webapplicatie te ontwikkelen waarmee gebruikers boeken kunnen bekijken, reserveren, aankopen en beoordelen. De applicatie bestaat uit een frontend, een backend en een databank.

## 2. Uitgevoerde fases

| Fase | Activiteiten | Status |
|---|---|---|
| 1. Analyse | De opdracht en functionele vereisten bekijken. | Uitgevoerd |
| 2. Architectuur | De structuur van de frontend, backend en databank bepalen. | Uitgevoerd |
| 3. Backend | API-endpoints ontwikkelen voor boeken, gebruikers, reservaties, aankopen en reviews. | Uitgevoerd |
| 4. Databank | Gegevens opslaan en beheren met SQLite en SQLAlchemy. | Uitgevoerd |
| 5. Frontend | De gebruikersinterface maken en verbinden met de backend. | Uitgevoerd |
| 6. Testen | De belangrijkste functionaliteiten en foutscenario's testen. | Uitgevoerd |
| 7. Documentatie | De README en architectuurdocumentatie schrijven. | Uitgevoerd |
| 8. Eindcontrole | De applicatie controleren en de GitHub-repository voorbereiden voor indiening. | Uitgevoerd |

## 3. Belangrijkste functionaliteiten

- Boeken bekijken met hun gegevens en beschikbare voorraad.
- Een account registreren en inloggen.
- Boeken reserveren.
- Een reservatie afronden als aankoop.
- Aangekochte boeken in het gebruikersprofiel bekijken.
- Reviews met een score en tekst toevoegen aan aangekochte boeken.
- Reviews op de detailpagina van een boek bekijken.

## 4. Eindresultaat

De boekenwinkel werd opgebouwd met een frontend, een backend en een databank. De documentatie beschrijft de projectstructuur, de architectuur en de belangrijkste functionaliteiten.
